    02 내 규칙·가이드

    메일로 가입하면 내 규칙과 가이드 문서를 쓸 수 있습니다

    금지어, 바꿀 말, 정규식, 문장 끝 어미 조건을 YAML로 저장합니다. 문체 가이드나 용어집을 올리면 문단마다 관련 조각을 찾아 AI가 어긋나는지 판정하고 근거를 같이 보여 드립니다.

    내용 보기
    • 이용 목적: 회원 식별, 내 규칙 저장, 가이드 문서 등록 기능 제공, 동의 처리 결과 같은 서비스 안내
    • 수집 항목: 메일 주소, 동의 일시와 동의 문구 판, 직접 저장한 규칙과 가이드 문서
    • 보유·이용 기간: 탈퇴할 때까지. 탈퇴하면 메일 주소, 동의 기록, 규칙, 가이드 문서를 바로 지웁니다. 열쇠를 잃어 탈퇴할 수 없으면 Define404 연락처(contact.define404.com)로 요청해 주세요
    • 동의하지 않으셔도 됩니다. 다만 동의하지 않으면 가입과 내 규칙·가이드 문서 기능을 쓸 수 없습니다. 기본 규칙 검사는 그대로 쓸 수 있습니다
    내용 보기
    • 이용 목적: Define404의 새 기능, 설치·가이드 정리 대행 같은 광고성 정보를 메일로 보내기
    • 수집 항목: 메일 주소, 동의 일시
    • 보유·이용 기간: 동의를 철회하거나 탈퇴할 때까지. 동의한 지 2년이 지나면 동의를 끝내고 다시 묻습니다
    • 광고성 메일은 한국 시각 오전 8시부터 오후 9시 전까지만 보내고, 제목은 (광고)로 시작합니다
    • 동의하지 않으셔도 됩니다. 동의하지 않아도 가입과 모든 기능을 똑같이 쓸 수 있습니다. 언제든 메일 속 링크나 이 화면에서 비용 없이 철회할 수 있고, 처리 결과는 메일로 알려 드립니다

    가입하면 이 브라우저에 열쇠가 저장됩니다. 메일 확인 기능은 아직 없어서, 열쇠를 잃어버리면 같은 메일로 다시 받을 수 없습니다.

      03 쓰는 길

      AI 도구 안에서, 커밋 전에, 답변이 끝날 때

      같은 규칙 엔진을 MCP 서버, 명령줄, Claude Code 훅에서 씁니다. 설치 순서는 GitHub README에 있습니다.

      MCP 서버
      Claude 데스크톱, Claude Code, Cursor에서 check_text, add_rule, add_guide_document 도구로 부릅니다.
      명령줄
      munche-meo check docs/ 위반이 있으면 실패로 끝나서 커밋 전 검사나 CI에 넣을 수 있습니다.
      Claude Code 훅
      답변이 끝날 때 마지막 답변을 검사하고, 걸리면 Claude가 그 부분만 다시 씁니다.

      팀 문체 가이드를 규칙으로 옮기는 일이 막막하다면

      회사 브랜드 보이스 문서, 사내 용어집을 규칙 파일과 가이드 문서로 정리하고 팀 도구에 설치해 드립니다.
